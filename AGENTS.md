# SiDoel — Sistem Data Online Sekolah

Dokumentasi ringkas proyek agar sesi berikutnya tidak perlu membuka file satu per satu.
Terakhir disusun: hasil pembacaan menyeluruh seluruh folder `C:\xampp\htdocs\sidoel`.

---

## 1. Ringkasan Proyek

Aplikasi web admin sekolah berbasis **PHP native (mysqli)** + **Bootstrap 5 / AdminLTE 4**.
Menangani Data Master (sekolah, tahun ajaran, jurusan, mapel, kelas, user, guru), Data Siswa
(siswa aktif, penempatan kelas, kenaikan kelas, alumni, sebaran), PPDB (tarik siswa), dan KBM (wali kelas).

- **Root web server:** `C:\xampp\htdocs\sidoel`
- **Folder aplikasi utama:** `admin/`
- **Bahasa komunikasi proyek:** Indonesia
- **Bukan repo git.**
- **Database:** `data_backup` (lihat `admin/koneksi.php` → host `localhost`, user `root`, password kosong).
- **Dependensi:** `phpoffice/phpspreadsheet ^5.2` (`admin/composer.json`, sudah terinstal di `admin/vendor/`).

## 2. Konvensi & Pola Kode

- **Routing:** `index.php` → `include('konten.php')`; `konten.php` memilih file via `switch ($_GET['menu'])`, default `beranda`. Kasus routing ada di `konten.php`.
- **Aksi/form:** form mengarah ke `aksi/aksi_<entitas>.php`. Handler memproses lalu `header("Location: ../index.php?menu=...&pesan=..."); exit;`.
- **Alert global:** `index.php` (baris ~626-659) membaca `$_GET['pesan']` dan menampilkan **SweetAlert2**.
  Nilai pesan yang dikenali: `tambah`, `edit`, `hapus` (sukses), `duplikat` (warning),
  `kosong`, `error`, `invalid`, `tolak` (error), `pindah`, `kembali`, `tarikppdb`, `validasi` (sukses).
  → Halaman baru **tidak perlu** menampilkan alert sukses/hapus sendiri; cukup redirect dengan `?pesan=`.
- **Beberapa halaman** masih memakai `$_SESSION['alert']` lokal (tahun_ajar.php, user.php, wali_kelas.php, kelas.php, mapel.php). Mapel: `session_start()` di-komentari sehingga alert lokal ini bisa tidak tampil.
- **Tahun Ajaran aktif:** disimpan di `$_SESSION['tahun_ajaran_aktif']` (berisi **string** `tahun_ajaran`, mis. `"2026/2027"`, bukan id).
  - Di-set di `aksi/aksi_login.php` (saat login) dan `aksi/aksi_rubah_tahun.php` (ganti TA di sidebar).
  - Halaman umumnya me-resolve id dari nama: `SELECT id_tahun_ajaran FROM dt_tahun_ajar WHERE tahun_ajaran = ?`.
  - `index.php` menyediakan dropdown ganti TA di sidebar (`#select-ta-aktif` → `aksi/aksi_rubah_tahun.php`).
- **Tata letak sidebar (`index.php`):** grup header = **DATA MASTER** (Data Referensi ▸ [Data Sekolah, Kop Sekolah, Tahun Ajaran, Jurusan, Mata Pelajaran, Kelas/Rombel], Data Guru & Staf), **PPDB** (Tarik Siswa), **DATA SISWA** (Data Siswa ▸ [Siswa Aktif, Kelengkapan Data, Penempatan Kelas, Info Kelas/Rombel, Kenaikan Kelas, Sebaran Siswa, Alumni, Foto Siswa]), **KELAS & PENUGASAN** (wali_kelas, sekretaris_kelas), **PENDIDIKAN & KBM** (sub-grup ▸: *Penugasan & Referensi* [`$kbmReferensiMenus` = guru_mapel, pengampu_mapel], *Pembelajaran* [`$kbmPembelajaranMenus` = jadwal, kalender_akademik]), **MONITORING & REKAP** [`$monitoringMenus` = dashboard_wali_kelas, rekap_absensi, rekap_jurnal, jurnal_kelas], **KEUANGAN (SPP)** [`$keuanganMenus` = spp_tarif, spp_tagihan, spp_pembayaran, spp_rekap], **LAPORAN & CETAK** (kartu_siswa, item datar), **ADMINISTRASI SISTEM** (User Pengguna, Log Aktivitas, Backup & Restore, Manajemen Tahun Ajaran). Header DATA MASTER disembunyikan bila tidak ada menu yang diizinkan. Grup didefinisikan sebagai array menu di awal `index.php`; tiap item digating `boleh_menu()` dan tiap grup `ada_menu_izin()`.
- **DataTables** (dimuat di `index.php`): `#myTable` (default), `#myTable1` (`paging:false, scrollY:'300px'`), `#myTable2` (`paging:false, scrollY:'440px'`). Halaman baru cukup pakai id ini.
- **Select2** dipakai pada `#id_fk_guru` (modal tambah user). `dropdownParent` diset agar bekerja di dalam modal.
- **Peta:** Leaflet 1.9.4 + **Leaflet.markercluster 1.5.3** (CDN, dimuat di `index.php`), div `#mapSiswa`; data dari variabel PHP `$siswa_locations_json`, `$center_lat`, `$center_lng` yang di-inject di `index.php` (script init di `index.php` bawah, ~baris 740-804, guard `#mapSiswa`).
  - **PENTING (data koordinat):** `dt_siswa.lintang`/`bujur` bertipe **varchar(50)** dan sebagian besar memakai **koma desimal** (mis. `-8,68114`), jadi `is_numeric()` menolaknya. `denah_siswa.php` memakai helper `normalisasi_koordinat()` (ganti koma→titik), membalik tanda lintang positif (Bali = belahan selatan), lalu memfilter **bounding box Bali** (lat -9.5..-7.0, lng 114.0..116.5) untuk membuang outlier `(0,0)`, `(1,1)`, dsb. Rata-rata titik valid dipakai sebagai center. Data live TA 2027/2028: **288 titik valid, 8 invalid**. Tiap marker: `bindTooltip` nama saat hover + `bindPopup` detail (NIS/rombel) saat diklik.
  - **Pengecualian:** `konten/siswa_tambah.php`, `siswa_edit.php`, & `siswa/edit.php` memakai **Google Maps JS API** (bukan Leaflet), div `#map`, callback `initMap`, API key dari konstanta `GOOGLE_MAPS_API_KEY` (didefinisikan di `admin/koneksi.php`). Menentukan titik lewat klik peta / tombol "Posisi saya saat ini!" (geolocation) → isi `#latitude`/`#longitude` (readonly).
- **Library eksternal (CDN):** Bootstrap 5.3.7, Bootstrap Icons 1.13.1, DataTables 2.3.2, SweetAlert2 11, Select2 4.1.0-rc.0, Chart.js 4.4.1 (khusus beranda), OverlayScrollbars 2.11.0, Leaflet 1.9.4, Leaflet.markercluster 1.5.3, jQuery 3.6.0, `qrcode@1.5.3` (khusus halaman `kartu_siswa`).
- **Laporan & Cetak:** strategi **Print-to-PDF via browser** (tanpa library PDF). Helper bersama `konten/helper_laporan.php`: `laporan_sekolah($koneksi)` (profil sekolah), `laporan_logo_url($sekolah)`, `laporan_kop_aktif($koneksi)` (kop `status='aktif'`), `laporan_kop_html($sekolah,$kop_url)` (kepala surat: gambar kop **full-width** — `.laporan-kop-img img{width:100%;height:auto}` — bila ada; jika tidak logo+nama+alamat), `laporan_tanggal_id($ts)` (format "15 Oktober 2026"), `laporan_kepala_sekolah($koneksi)` (`['nama','nip']` dari `dt_guru WHERE sudah_lisensi_kepala_sekolah=1 ORDER BY id_guru LIMIT 1`), `laporan_footer_html($kepala,$tanggal)` (blok tanda tangan bawah: **Diterbitkan: <tgl>** + **Kepala Sekolah,** + nama + NIP; placeholder `……` bila belum ada kepala), `laporan_print_css()` (CSS `@media print`: menyembunyikan `.app-sidebar/.app-header/.app-footer/.app-content-header`; elemen non-cetak pakai class `.no-print`; **background dipaksa PUTIH** — `html, body, body.bg-body-tertiary, .app-wrapper, .app-content, .content-wrapper, .container-fluid` → `#fff !important`; `body.bg-body-tertiary` perlu specificity lebih tinggi dari utility `!important` AdminLTE; + `print-color-adjust: exact`). Menu tiap laporan didaftarkan di `AKSES_MENU` + sidebar grup **"LAPORAN & CETAK"** (`$laporanMenus` di `index.php`).
- **Zona waktu:** Asia/Makassar (WITA) — jam di header.
- **Password:** login admin kini **bcrypt**. Verifikasi terpusat di `admin/helper_auth.php`: `verifikasi_password()` menerima hash **bcrypt** (`password_verify`) ATAU **MD5 lama** (32 hex) untuk kompatibilitas; bila cocok dan masih MD5, otomatis di-upgrade ke bcrypt saat login (`upgrade_password_jika_perlu()`). Password baru (tambah/reset user di `aksi_user.php` + ganti password sendiri di `aksi_profil.php`) di-hash dengan `hash_password()` (bcrypt). Password **siswa** (`dt_siswa.password`) dan PPDB (`ppdb_*`) juga bcrypt.
  Password **siswa** (`dt_siswa.password`) dan PPDB (`ppdb_*`) memakai **bcrypt** (`password_hash`, PASSWORD_BCRYPT).
- **Kontrol akses (RBAC):** `admin/akses.php` (const `AKSES_MENU`, `AKSES_MENU_BEBAS`, `AKSES_AKSI_MENU` + fungsi `boleh_menu()`, `ada_menu_izin()`, `boleh_aksi()`).
  - `index.php` `require_once('akses.php')` lalu redirect ke `?menu=beranda&pesan=tolak` bila `!boleh_menu($level_user, $activeMenu)`; item sidebar & shortcut di `beranda.php` digating dengan `boleh_menu()`/`ada_menu_izin()`.
  - Tiap file `aksi/*` (kecuali `aksi_login.php`) menyisipkan `require_once(__DIR__ . '/akses_guard.php');` di baris awal → cek login + `boleh_aksi(basename(__FILE__))`; file tak terpetakan di `AKSES_AKSI_MENU` = bebas.
  - `level_user`: **Admin** = `'*'` (semua); **Kurikulum** = data master akademik + penugasan (`guru_mapel`, pengampu, wali, sekretaris) + jadwal/kalender + monitoring (absensi/jurnal) + data siswa + PPDB + laporan + **SPP penuh** (`spp_tarif`, `spp_tagihan`, `spp_pembayaran`, `spp_rekap`) (tanpa `user`); **Kesiswaan** = kelas/siswa/PPDB/alumni + penugasan wali/sekretaris + monitoring absensi & jurnal kelas + laporan + **hanya `spp_rekap`** (tanpa data master akademik, jadwal, kalender, rekap jurnal guru, tarif/tagihan/pembayaran SPP); **Guru** = beranda/dashboard_wali_kelas/info_kelas/detail_kelas/denah_siswa/siswa_aktif/siswa_detail (tanpa CRUD penugasan wali, tanpa menu SPP). Hanya Admin yang boleh menu `user`. `import_preview` diizinkan untuk Kurikulum/Kesiswaan agar redirect preview import tidak tertolak.
  - Menu bebas (semua level): `beranda`, `logout`, `aktivitas_ppdb`, `profil`.

## 5. Alur Kenaikan Kelas (`naik_kelas.php` + `kenaikan_kelas.php`)

Wizard 3 langkah; TA target = `$_SESSION['tahun_ajaran_aktif']`, TA sumber = id terbesar yang `< target`.

1. **`persiapan_kelas`** — clone kelas X→XI & XI→XII ke TA target. Pola array `[['X','XI'],['XI','XII']]`, dibungkus `begin_transaction`.
2. **`kenaikan`** (X→XI, XI→XII): **HANYA `INSERT`** baris baru `dt_kelas_siswa` untuk TA target (keterangan "Naik Kelas") + **`UPDATE dt_siswa SET id_tahun_ajaran=target, rombel=...`**.
   - **Tidak ada DELETE.** Baris penempatan TA lama tetap tersimpan (histori). `dt_siswa` tidak dihapus.
   - Idempotent via cek `EXISTS` (`sudah_pindah`).
3. **`luluskan`** (XII → alumni): `INSERT` ke `dt_alumni`, lalu **`DELETE`** dari `dt_kelas_siswa` **dan** `dt_siswa`.

**Konsekuensi:** `dt_siswa.id_tahun_ajaran` & `rombel` ditimpa → filter TA lama tak menemukan siswa di `dt_siswa`.
Namun baris penempatan lama tetap ada di `dt_kelas_siswa`, jadi riwayat tidak hilang.

**FIX tampilan (sudah dikerjakan):** `konten/siswa_aktif.php` kini membaca daftar & statistik dari **riwayat `dt_kelas_siswa`** untuk TA yang dipilih di dropdown sidebar (bukan hanya `dt_siswa.id_tahun_ajaran`).
Pola: `LEFT JOIN dt_kelas_siswa ks ON ks.id_siswa=s.id_siswa AND ks.id_tahun_ajaran = <TA terpilih>` + `WHERE (s.id_tahun_ajaran = <TA> OR ks.id_kelas_siswa IS NOT NULL)`.
Hasil (data live): TA 2026/2027 → 734 siswa, TA 2027/2028 → 724 siswa. Rombel ditampilkan dari `dt_kelas` tahun tsb.
Halaman lain (`detail_kelas.php`, `info_kelas.php`, `denah_siswa.php`, `rekap_kelas.php`) sudah history-aware / berbasis `dt_kelas_siswa` sehingga ikut menyesuaikan TA dari sidebar.
`denah_siswa.php` & `rekap_kelas.php` memakai pola `LEFT JOIN dt_kelas_siswa ks ON ks.id_siswa=s.id_siswa AND ks.id_tahun_ajaran=<TA>` + `WHERE (s.id_tahun_ajaran=<TA> OR ks.id_kelas_siswa IS NOT NULL)`, rombel di-resolve dari `dt_kelas`.

## 7. Quirk & Jebakan Penting

- **`dt_kelas_siswa` punya 813 baris orphan** (id_siswa tak ada di `dt_siswa`). Query agregat siswa **WAJIB** `INNER JOIN dt_siswa` atau filter `id_tahun_ajaran` + `COUNT(DISTINCT s.id_siswa)`, jika tidak angka membengkak.
- **Filter tahun ajaran wajib.** Banyak query agregat harus `AND ksw.id_tahun_ajaran = '$id_ta'`. `id_ta` berasal dari nama TA di session.
- **Login = MD5** (jangan ubah ke bcrypt tanpa migrasi data). Password siswa/PPDB = bcrypt.
- **`assets/img/`** bukan `assets/images/`.
- **SweetAlert global** via `?pesan=`; tak perlu alert lokal untuk sukses.
- Chart.js hanya di `beranda.php`; Leaflet hanya relevan di `denah_siswa`/`data_sekolah`.
- PHP native mysqli, **tanpa framework**. Banyak query masih interpolasi string (rawan SQLi) — hati-hati saat menambah kode, utamakan `prepare`.
- **RBAC (lihat §2):** enforcement ganda (menu di `index.php` + guard tiap file `aksi/*`). Menambah menu/handler baru → daftarkan di `AKSES_MENU` (per level) & `AKSES_AKSI_MENU` (file aksi → menu); jangan lupa `require_once(__DIR__ . '/akses_guard.php');` di handler aksi baru.
- **Audit log (lihat §4):** setiap handler aksi yang memakai `akses_guard.php` **otomatis** tercatat di `dt_audit_log` (status `ok`/`denied`) via `audit_register()` (di akhir request). Login/logout dicatat manual di `aksi_login.php`. Tidak perlu mengubah handler untuk logging; cukup pastikan tabel `dt_audit_log` ada (`audit_log.sql`). `keterangan` = ringkasan param JSON (key ber-`password`/`token`/`secret` → `***`).
